MyHealthBridge 🩺🌉

MyHealthBridge is a lightweight, privacy-focused health tracking prototype designed to demonstrate how patients could record health measurements and generate structured reports for potential sharing with healthcare providers.

⚠️ DEMO / PORTFOLIO PROJECT ONLY

This is a personal developer portfolio concept and is not an official or live NHS service. It is not intended for clinical use or use with real patient data.

Key Features
🩸 Blood Pressure Tracking – Systolic/Diastolic readings with 7-day averages
🫁 Peak Flow Tracking – PEFR readings and personal best tracking
⚖️ Weight Tracking – Kilograms with Stones & Pounds conversion
📄 PDF Reports – Generate structured demonstration reports
📊 CSV Export – Export individual or combined health data
📋 Plain Text Export – Demonstrates structured information for potential online consultation workflows
🔒 Local Storage – Demonstration data is stored within the browser
Technology
NHS.UK Frontend – UI demonstration
Chart.js – Data visualisation
html2pdf.js / jsPDF – PDF generation
Browser LocalStorage – Client-side demonstration storage
GitHub Pages – Static deployment
